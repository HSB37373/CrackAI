> 악성 민원을 자동 감지하고, 담당자 대신 AI가 표준화된 음성으로 응대하는 실시간 민원 상담 플랫폼

## 🎯 프로젝트 개요

공공기관 민원 담당자는 악성 민원인의 폭언·협박에 직접 노출되어 심각한 정신적 피해를 입고 있습니다.  
본 시스템은 **AI가 악성 민원을 먼저 감지하고, 담당자 대신 응대**함으로써 세 가지 가치를 실현합니다.

| 핵심 가치 | 설명 |
|---|---|
| 🧑‍💼 담당자 보호 | 폭언·위협에 직접 노출되는 시간 최소화 |
| 📋 민원 처리 지속 | 악성 표현이 있어도 정당한 민원은 AI가 계속 처리 |
| 🎙️ 응대 표준화 | 공식 행정정보를 기반으로 일관된 안내 제공 |

## ⚙️ 악성 민원 판단 방식

```
위험도 점수 = 욕설·비속어(30%) + 위협 표현(35%) + 분노 표현(20%) + 반복 발화(15%)
```

| 점수 | 단계 | 시스템 행동 |
|---|---|---|
| 0 ~ 14 | 🟢 정상 | 담당자 상담 유지 |
| 15 ~ 29 | 🟡 주의 | 경고 안내 메시지 |
| 30 ~ 54 | 🔴 위험 | **AI 상담 자동 전환** |
| 55 ~ 100 | 🚨 심각 | 즉시 전환 + 경고 강화 |

## 🗺️ 서비스 흐름

```
민원인 음성/텍스트 입력
        ↓
  STT (음성→텍스트)
        ↓
  악성 민원 여부 분석
   ├─ 정상 → 상담 계속
   └─ 악성 → 경고 후 AI 전환
                ↓
       행정정보 FAQ 검색
                ↓
          답변 문장 생성
                ↓
     TTS (텍스트→음성) 출력
```

## 🚀 실행 방법

### 1. 의존성 설치
```bash
pip install -r requirements.txt
```

### 2. 서버 실행
```bash
uvicorn main:app --reload --port 8000
```

### 3. 브라우저 접속
```
http://localhost:8000
```

> JupyterHub 환경에서는 `/user/<username>/proxy/8000/` 경로로 접속

## 📊 API 엔드포인트

| 메서드 | 경로 | 설명 |
|---|---|---|
| POST | `/analyze` | 발화 텍스트 분석 (위험도 + 민원 분류) |
| POST | `/respond` | AI 답변 생성 (FAQ 또는 Claude API) |
| GET | `/summary/{session_id}` | 상담 종료 후 요약 보고서 |
| GET | `/faq` | 행정 민원 FAQ 전체 조회 |
